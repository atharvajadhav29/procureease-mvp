# ProcureEase MVP

A self-contained, funding-demo-ready Source-to-Pay procurement web application.

## Demo logins
- Buyer: `buyer@procureease.com` / `Buyer@123`
- Vendor: `vendor@procureease.com` / `Vendor@123`
- Admin: `admin@procureease.com` / `Admin@123`

Open `index.html` in a browser. Demo state persists in browser local storage.
